# Cyber_Ops_Lab

A hands-on cybersecurity portfolio focused on SOC operations, network analysis, and security monitoring. This lab environment covers real-world scenarios using industry-standard tools and techniques.

---

## 🎯 Purpose

This repository serves as a structured lab portfolio demonstrating practical skills in:

- Network traffic analysis and anomaly detection
- Firewall configuration and network security hardening
- Security log parsing and automation with Python
- Incident response fundamentals
- Security Operations Center (SOC) workflows

---

## 🛠️ Tools Used

| Tool | Purpose |
|------|---------|
| **Wireshark** | Network packet capture and traffic analysis |
| **Cisco Packet Tracer** | Network simulation and firewall/ACL configuration |
| **Linux CLI** | System administration, log analysis, and scripting |
| **Python** | Automation, log parsing, and security scripting |
